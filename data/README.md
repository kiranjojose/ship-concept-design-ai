# Data and its terms

The MIT License in the repository root covers the project's own software and
documentation. It does **not** cover the transcribed material in this folder.

| Folder | Contents | Origin | Terms |
|---|---|---|---|
| `reference/` | Tables transcribed from the 2019 B.Tech design report (dimensions, offsets, hydrostatics, resistance, weights, holds, stability). `parent_ships_table_2_1.csv` reproduces the report's extract from a register ship book. | K. J. Puthussery, B.Tech design report, 2019. Each CSV names its page and table in the first line. | Rights remain with the report's author and, for the parent-ship data, the original publisher. Included so the experiments can be reproduced. Not licensed under MIT. |
| `literature/` | Inputs and printed results of the worked example on p. 170 of Holtrop & Mennen (1982), *An approximate power prediction method*, International Shipbuilding Progress 29(335). | The published paper. | Rights remain with the publisher. Quoted as a verification benchmark. Not licensed under MIT. |
| `raw/` | Original source documents. | Kept locally. | Git-ignored. Not distributed. |
| `processed/`, `synthetic/` | Files generated by the code. | This repository. | MIT, as generated output of the software. |

If you reuse the transcribed tables, cite the original source rather than this repository.
